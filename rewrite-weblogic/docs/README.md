# Welcome to WebLogic Server application upgrade tooling

WebLogic Server application upgrade tooling employs [OpenRewrite](https://github.com/openrewrite/rewrite) recipes for upgrading applications to newer versions of WebLogic Server, Java, Jakarta EE, and related versions of Jakarta Server Faces, Spring Framework, and Hibernate. Here, you'll find recipes that perform the functions you need to successfully upgrade your applications. Use [Rewrite WebLogic](../README.md) recipes to migrate your applications to WebLogic 26.1.0, Jakarta EE 11, and Java 21 or Java 25; WebLogic 15.1.1, Jakarta EE 9.1, and Java 17 or Java 21; or WebLogic 14.1.2 and Java 17 or Java 21.
